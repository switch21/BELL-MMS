# Liste de controle des colonnes de catalogue PostgreSQL 17 utilisees par les scripts de collage.
# Une colonne inventee ne casse pas la DDL : elle casse le bloc de controle AVANT COMMIT, donc le
# collage entier est annule (erreur 42703 en PL/pgSQL). Constate le 2026-11-16 sur apply_024 avec
# t.relid (reel : t.tgrelid) et t.tginternal (reel : t.tgisinternal).
# Format : table = colonne, colonne, ...  (les alias d'instruction $garde$ / $ancre$ ne sont pas des tables)
pg_trigger = tgschema, tgname, tgrelid, tgparentid, tgtype, tgenabled, tgisinternal, tgconstrrelid, tgconstrindid, tgconstraint, tgdeferrable, tginitdeferred, tgnargs, tgattr, tgargs, tgqual, tgoldtable, tgnewtable, tgoid, oid

# Exception declaree, volontaire : relforcerowsecurity, relispopulated, relreplident, relispartition, relrewrite, relacl, reloptions, relpartbound... existent en PG 17 mais sont HORS du besoin de
# ces scripts. Les refuser ici est un choix : une colonne que personne dans le depot n'ecrit ne doit
# pas devenir une dependance implicite. Elles seront ajoutees le jour ou un script les utilise.
